# Archive Policy

The public repository keeps the core implementation, reproducible summaries, and publish-safe visuals.

The following local materials are intentionally left outside version control:

- planning drafts and proposal documents;
- internal runbooks and navigation notes;
- oversized experiment artifacts, checkpoints, and dataset exports;
- local handoff documents tied to a single workstation layout.

This keeps the repository readable as a portfolio project while preserving the full local research workspace.
